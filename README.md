# 📚 Paper Study — 논문 학습 노트

PDF 논문을 업로드하면 **내용을 이해하기 쉽게 깔끔히 정리**해 주고, **Notion처럼 계속 기록**할 수 있는 논문 학습 사이트입니다.

모든 처리는 브라우저 안에서 이루어집니다. PDF나 노트는 서버로 전송되지 않고 이 브라우저(localStorage)에만 저장됩니다.

## ✨ 주요 기능

- **PDF 자동 정리** — PDF를 업로드하면 제목·저자·초록·섹션을 자동으로 인식하고, 읽기 좋게 재구성합니다. (API 키 불필요)
- **핵심 요약** — 키워드 추출, 핵심 문장(추출 요약), 예상 읽기 시간을 보여줍니다. (API 키 불필요)
- **AI 심화 요약** — Gemini가 논문을 한국어로 구조화해 깊이 있게 요약합니다.
- **🎓 AI 교수 채팅** — 논문 내용을 근거로 무엇이든 질문하고 답을 얻습니다. 대화는 자동 저장됩니다.
- **📊 인포그래픽 생성** — 논문 핵심을 한 장의 이미지로 시각화하고 PNG로 내려받습니다.
- **🧠 학습 도구** — AI가 만든 4지선다 퀴즈와 핵심 용어 플래시카드로 이해도를 점검합니다.
- **📝 Notion식 블록 노트** — 슬래시(`/`) 메뉴와 마크다운 단축키로 제목·목록·할 일·인용·코드 블록을 작성하며 기록합니다. 입력 즉시 자동 저장됩니다.
- **라이브러리 & 검색** — 업로드한 논문을 사이드바에서 관리하고 검색합니다.
- **Markdown 내보내기** — 작성한 노트를 `.md` 파일로 내보냅니다.

AI 기능(요약·채팅·인포그래픽·퀴즈·카드)은 **Google Gemini API**를 사용합니다.
우측 상단 **⚙ 설정**에서 본인의 Gemini API 키를 입력하세요. (기본 모델: 텍스트 `gemini-3.1-flash-lite`, 이미지 `gemini-3.1-flash-image`)
키는 이 브라우저에만 저장되며, 요청은 브라우저에서 Gemini API로 직접 전송됩니다.

## 🚀 로컬 실행

```bash
npm install
npm run dev      # http://localhost:5173
```

프로덕션 빌드:

```bash
npm run build    # dist/ 생성
npm run preview  # 빌드 결과 미리보기
```

## 📝 노트 작성 팁 (Notion식 단축키)

| 입력 | 결과 |
| --- | --- |
| `/` | 블록 종류 선택 메뉴 |
| `# ` `## ` `### ` | 제목 1·2·3 |
| `- ` 또는 `* ` | 글머리 목록 |
| `[] ` | 할 일(체크박스) |
| `> ` | 인용 |
| ` ``` ` | 코드 블록 |
| `--- ` | 구분선 |
| Enter | 새 블록 / 목록 계속 |
| Shift+Enter | 한 블록 안에서 줄바꿈 |
| 빈 블록에서 Backspace | 이전 블록과 합치기·삭제 |

## 🤖 AI 설정

우측 상단 **⚙ 설정**에서 Gemini API 키와 모델을 입력합니다.
API 키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 발급할 수 있습니다.
키는 브라우저에만 저장되며, 요청은 브라우저에서 Gemini API로 직접 전송됩니다.

## 🧰 기술 스택

Vite · React · TypeScript · Tailwind CSS · pdfjs-dist · Google Gemini API

## ⚠️ 참고

- 스캔된 이미지 PDF(텍스트 레이어 없음)는 OCR이 필요해 지원되지 않습니다.
- 데이터는 브라우저 localStorage에 저장되므로 용량 제한(~5MB)이 있고, 브라우저 데이터를 지우면 함께 삭제됩니다. 중요한 노트는 Markdown으로 내보내 두세요.
